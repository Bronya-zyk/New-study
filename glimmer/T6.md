# 不同发行版的区别

Linux 内核只是操作系统的核心程序，只负责硬件调度、内存管理等底层功能，Linux 发行版就是在内核之上，打包了软件包管理器、系统库、桌面环境、各类工具软件组成的完整操作系统。不同发行版只是基于同一个 Linux 内核，在包管理、设计理念、目标用户上有区别（具体的我也看不懂啊）

# 目录

Linux 所有目录都挂载在根目录下，是树形文件系统，没有 Windows 的 C/D 盘符。

1. **/etc**：存放系统配置文件。比如用户信息、服务配置、环境变量，很多软件的配置文件都在这里。
2. **/usr**：存放用户安装的程序、文档、库文件。相当于 Windows 的 Program Files，里面有`/usr/bin`存放用户命令。
3. **/tmp**：临时文件目录。所有用户都可以读写，系统重启后里面文件一般会自动清空。
4. **/home**：普通用户家目录。每个用户会在这里有一个同名文件夹，用来存放个人文件。例如用户`student`的家目录就是`/home/student`。
5. **/root**：超级管理员 root 的家目录，和普通用户家目录分开，不在 /home 下。
6. **/bin**：存放系统基础可执行命令（ls、cat、cp 等），系统启动就可以使用。
7. **/dev**：设备文件目录。Linux 把硬件当成文件，硬盘、网卡、鼠标都在这里。
8. **/var**：存放经常变化的数据。比如系统日志、数据库文件、缓存。

# Vim

| 按键  | 作用                                          |
| ----- | --------------------------------------------- |
| `i`   | 普通模式 → 插入模式，**光标前面输入**         |
| `a`   | 普通模式 → 插入模式，**光标后面输入**         |
| `o`   | 普通模式 → 插入模式，**在当前行下方新开一行** |
| `I`   | 在行首进入插入模式                            |
| `A`   | 在行尾进入插入模式                            |
| `Esc` | **任意模式返回普通模式**                      |
| `:`   | 普通模式输入冒号，进入底行模式                |
| `0`   | 跳到本行开头                                  |
| `$`   | 跳到本行末尾                                  |
| `gg`  | 跳到文件第一行                                |
| `G`   | 跳到文件最后一行                              |
| `nyy` | 复制n整行                                     |
| `p`   | 粘贴（粘贴到光标下方）                        |

| 关于文件保存的命令 | 功能                                   |
| ------------------ | -------------------------------------- |
| `:w`               | 保存文件（write）                      |
| `:q`               | 退出文件（quit，**不能有未保存修改**） |

| `:q!`              | **强制退出，放弃所有修改**（不保存）   |

# 用户权限

## 建立 

1. **root 用户**：拥有系统最高全部权限
2. **用户组**：可以把多个用户放到同一个组里，方便批量分配权限。

```
# 创建用户组
groupadd testgroup
# 创建新用户，并加入testgroup组
useradd -g testgroup testuser
# 设置用户密码
passwd testuser
```

```
# 创建测试文件
touch test.txt
# 修改权限，示例：所有者读写执行，组和其他人只读
chmod 744 test.txt
```

## 数字权限简化原理

r、w、x 分别对应数字：

- r（读）=4
- w（写）=2
- x（执行）=1

**所有者、同组用户、其他用户**，每一段用一个数字表示，所以一共三位

## 为什么不一直用root

root 拥有全部权限，一旦输错命令会误删系统文件，造成系统损坏；若程序被攻击，攻击者会获取最高权限，完全控制服务器

管理员操作时使用 sudo 临时提权即可
