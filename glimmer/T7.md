## sql语法

### 库：

```
-- 1.查看所有数据库
SHOW DATABASES;

-- 2.创建数据库
CREATE DATABASE 库名;（若已存在会报错）
-- 安全写法：不存在才创建
CREATE DATABASE IF NOT EXISTS student_db;

-- 3.选择/进入数据库（必须执行，不然建表会报错No database selected）->也可以图形化界面双击
USE student_db;

-- 4.删除数据库
DROP DATABASE IF EXISTS student_db;
```

### 表：

```sql
-- 1.查看当前库里面所有表
SHOW TABLES;

-- 2.创建表（咱们学生表例子）
CREATE TABLE student(
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '学生编号，主键自增',
    --COMMENT备注说明
    --PRIMARY KEY唯一标识，id不能重复
    --AUTO_INCREMENT自增，只能搭配数字主键使用，自动id+1
    
    name VARCHAR(20) NOT NULL COMMENT '姓名',
    --VARCHAR是可变字符串，(20)最多20个字符
    
    age INT COMMENT '年龄',
    
    gender CHAR(1) COMMENT '性别'
    --CHAR(1)固定长度1
);

-- 3.查看表结构（表头数据类型）
DESC student;

-- 4.删除整张表
DROP TABLE IF EXISTS student;
```

### 查

```sql
-- 查询表中所有列所有数据，“*”代指全部列
SELECT * FROM student;

-- 只查指定列（姓名、年龄）
SELECT name, age FROM student;

-- 条件查询：只查年龄=18的学生
SELECT * FROM student WHERE age = 18;
--“=”精确匹配

-- 模糊查询：名字带"张"的学生
SELECT * FROM student WHERE name LIKE '%张%';
--LIKE是模糊匹配
--通配符（模糊）->“%”代指多个字符（可以是0个），“_”代指一个
```

### 插

```sql
-- 插入一条完整数据
INSERT INTO student(name,age,gender,address,phone)
VALUES ('王五',20,'男','渝中区','13512345678');
VALUES()--可以接多行
```

### 改

```sql
-- 修改张三的年龄为19
UPDATE student SET age=19 WHERE name='张三';
```

### 删

```sql
-- 删除名字叫李四的这一行记录
DELETE FROM student WHERE name='李四';
```

### 补充

1. `WHERE`：条件筛选，用来过滤数据，`=`大于`>`小于`<`
2. `PRIMARY KEY`：主键，唯一标识一行，不能重复、不能为空
3. `AUTO_INCREMENT`：自增，id 自动 + 1，不用手动填写
4. `NOT NULL`：不能为空
5. `COMMENT`：注释，只是说明文字，不参与运行
6. `--`：单行注释，后面写说明，MySQL 不会执行这一行文字
7. `UPDATE`、`DELETE` **一定要加 WHERE 条件**，否则清空整张表！
8. 语句末尾英文分号 `;`

### 数据类型

int，double之外，还支持date（XXXX-XX-XX），DECIMAL(m,n)（共m位，n位小数）

# HTTP

## T1

一种通信格式，不论系统，只要格式正确即可通信

<img src="C:\Users\GUN_zyk\AppData\Roaming\Typora\typora-user-images\image-20261002230727367.png" alt="image-20261002230727367" style="zoom:67%;" />

- Method：GET
- 请求 Header 信息：
  - `User-Agent`：浏览器标识
  - `Accept`：客户端能接收的数据类型
  - `Host`：目标服务器域名
  - `Cookie`：网站存储在本地的用户信息
  - `Accept-Encoding`：支持的压缩格式
- **服务器返回内容**：HTML 网页源码、状态码`200 OK`、响应头、网页资源。
- 一次 HTTP 请求组成
  - **请求行**：Method + URL + HTTP 版本，表达请求方法、资源地址
  - **请求头（Headers）**：键值对，附加请求元信息
  - **空行**：分隔请求头与请求体
  - **请求体（Body）**：POST 等方法携带的数据，GET 一般没有请求体
- 常见 HTTP 请求方法
  - `GET`：查询 / 获取资源，无请求体，参数放 URL
  - `POST`：提交数据、新建资源，携带请求体
  - `PUT`：更新资源
  - `DELETE`：删除资源
  - `HEAD`：只获取响应头，不要响应体，用于探测
