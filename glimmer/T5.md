# 项目结构

> 我先让AI完成了整个任务（很多东西完全陌生，所以我打算以解释代码的方式来学习）

这是一个**Java 原生 Http 服务端 + Http 客户端**的简易快递查询 Demo，**没有 SpringBoot**，用 JDK 自带`com.sun.net.httpserver`实现 Web 服务。 结构：

```
com.express
├─ QueryRequest.java     // 客户端发给服务器的数据模型（请求体）
├─ QueryResponse.java    // 服务器返回给客户端的数据模型（响应体）
├─ Server.java           // Http服务端，监听端口，接收客户端POST请求
└─ Client.java           // Http客户端，输入单号手机号，POST请求服务器
```

1.先建立QueryRequest请求实体，private快递单号手机号

2.再建立QueryResponse响应实体，负责返回查询结果

## HTTP

### HttpServer

| 方法                              | 作用                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| `createContext("/path", handler)` | 注册路径，把`/query`路径绑定到处理器 HttpHandler，返回 HttpContext |
| `setExecutor(Executor executor)`  | 线程池。null = 默认单线程（同一时间只能处理 1 个请求）       |
| `start()`                         | **启动服务器**，开始监听端口，不会阻塞主线程                 |
| `stop(int delay)`                 | 关闭服务；delay = 等待多少秒结束现有请求，0 = 立刻关闭       |

### HttpHandler

只有一个抽象方法，要重写具体业务逻辑，这就是connect后处理的地方

### HttpExchange

客户端的请求信息存在exchange



- 请求相关方法（读客户端发过来的数据）

| 方法                           | 作用                                                 |
| ------------------------------ | ---------------------------------------------------- |
| `String getRequestMethod()`    | 获取请求方法，返回字符串`GET` / `POST` / `PUT`       |
| `String getRequestURI()`       | 获取请求 URI，如`/query`                             |
| `String getRequestProtocol()`  | 获取 HTTP 版本，`HTTP/1.1`                           |
| `InputStream getRequestBody()` | **获取请求体输入流**，POST 的 JSON / 表单从这里读！  |
| `Headers getRequestHeaders()`  | 获取**请求头**，可以拿到 Content-Type、User-Agent 等 |



- 响应相关方法（返回数据给客户端）

| 方法                                                  | 作用                                                         |
| ----------------------------------------------------- | ------------------------------------------------------------ |
| `Headers getResponseHeaders()`                        | 拿到**响应头集合**，设置返回给浏览器 / 客户端的头。⚠️ 必须在 sendResponseHeaders 之前调用！ |
| `sendResponseHeaders(int rCode, long responseLength)` | 发送状态码 + 响应头（前面重点讲过）                          |
| `OutputStream getResponseBody()`                      | **响应体输出流**，写 JSON、文本给客户端。⚠️ 必须在 sendResponseHeaders 之后调用！ |
| `void close()`                                        | 关闭本次请求，释放资源                                       |

### Headers

本质就是`Map<String, List<String>>`



### HttpURLConnection向客户端发送请求

| 方法                          | 作用                                |
| ----------------------------- | ----------------------------------- |
| `setRequestMethod("POST")`    | 设置请求方法 GET POST               |
| `setRequestProperty(key,val)` | 设置请求头                          |
| `setDoOutput(true)`           | 开启请求体（POST 必须）             |
| `getOutputStream()`           | 输出流，写 JSON 请求体              |
| `getResponseCode()`           | 拿到服务返回的 HTTP 状态码 200 /404 |
| `getInputStream()`            | 读取服务端返回的响应体（成功时）    |
| `getErrorStream()`            | 读取错误响应（4xx/5xx 时）          |
| `disconnect()`                | 断开连接                            |

> GET和POST的区别
>
> POST有请求体放数据，GET的数据在网址后面，例：`http://127.0.0.1:8080/query?expressNo=SF123456`

关于connect的步骤

```
// 1. 构造URL对象
URL url = URI.create(SERVER_URL).toURL();

// 2. 打开连接对象（⚠️此时还没建立网络TCP连接！）
HttpURLConnection connection = (HttpURLConnection) url.openConnection();

// 3. 设置请求方法 POST
connection.setRequestMethod("POST");

// 4. 设置请求头（传JSON必须）
connection.setRequestProperty("Content-Type", "application/json");

// 5. setDoOutput(true) 【POST写body必须！】
connection.setDoOutput(true);

// 6. 获取输出流，写入请求体JSON（这一步才真正触发网络连接）
try (OutputStreamWriter writer = new OutputStreamWriter(connection.getOutputStream())) {
    writer.write(jsonStr);
}

// 7. 获取响应码，拿到服务器结果
int code = connection.getResponseCode();

// 8. 判断响应码，读取响应流
InputStream is;
if (code == 200) {
    is = connection.getInputStream();
} else {
    is = connection.getErrorStream(); // 报错的时候必须读错误流！
}
String respBody = readBody(is);

// 9. 断开连接，释放资源
connection.disconnect();
```
