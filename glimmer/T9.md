# Task1

## HttpURLConnection（应用层）

**工作方式**:同步阻塞，当前线程会一直等待服务器响应。

**特点：高度封装**：用于发送 HTTP，封装了 HTTP 协议

**缺点**：API 设计较老，功能相对基础

## SocketChannel（传输层）

> TCP

**工作方式**:支持**非阻塞**和**多路复用**

**特点**：可以将多个 Channel 注册到 Selector 上，通过一个线程轮询就绪事件（读、写、连接），极大降低了高并发下的线程开销。

**缺点**：编程模型复杂

## DatagramSocket（传输层）

> UCP

**工作方式**：**阻塞**，调用 `receive()` 会一直卡住，直到收到数据包。

**特点**：**无连接 **  **数据报**   **不可靠**  **大小限制**



**HttpURLConnection工程上不适用的原因：占用线程，只支持HTTP，且版本只支持1.1，相比之下socketchannel实现更为底层，实用性和适用性更好**，但是好处就是封装HTTP比较方便

### 一、 `java.net` 包（网络通信核心）

这是整个作业的基石，负责建立连接和收发数据。

**必须掌握的类：**

1. **`ServerSocket`** (服务器端)
   - `ServerSocket(int port)`：构造方法，绑定端口。
   - `accept()`：**核心方法**。阻塞等待客户端连接，返回一个 `Socket` 对象。
   - `close()`：关闭服务器。
   
2. **`Socket`** (客户端和服务器端通用)
   - `Socket(String host, int port)`：客户端构造方法，连接服务器。
   - `getInputStream()`：获取输入流（用于接收数据）。
   - `getOutputStream()`：获取输出流（用于发送数据）。
   - `getInetAddress()`：获取对方 IP 地址（返回 `InetAddress`）。
   - `getPort()`：获取对方端口号（用于日志命名）。
   - `close()`：关闭连接。
   
   > 我的理解：两个 java 类里面各有一个 socket 对象，然后两个 socket 对象的信息可以互传
   
3. **`InetAddress`**
   
   - `getHostAddress()`：获取 IP 字符串（如 "192.168.1.5"）。

### 二、 `java.io` 包（数据读写与文件操作）

负责把网络上的字节流转换成你能看懂的字符串，以及把日志写入本地文件。

**必须掌握的类：**

1. **`BufferedReader`** (读取网络数据)
   - `readLine()`：**核心方法**。按行读取客户端发来的消息，遇到换行符返回，流结束返回 null。
   
2. **`InputStreamReader`** (字节流转字符流)
   - 构造方法：`new InputStreamReader(socket.getInputStream())`，解决中文乱码。
   
3. **`PrintWriter`** (发送网络数据)
   
   - 构造方法：`new PrintWriter(socket.getOutputStream(), true)`。**注意第二个参数必须是 `true`**，表示自动刷新缓冲区（autoFlush），否则消息发不出去。
   - `println(String msg)`：发送一行消息并换行。
   
4. **`File`** (文件路径操作)
   
   - `File(String pathname)`：创建文件对象。
   - `exists()`：判断文件/文件夹是否存在。
   - `mkdirs()`：创建多级文件夹（用于创建 `log` 目录）。
   
5. **`FileWriter`** (写入日志文件)
   
   - 构造方法：`new FileWriter(file, true)`。**第二个参数 `true` 表示追加模式**，这样连续对话才会记录在同一个文件里，而不是覆盖。
   - `write(String str)`：写入字符串。
   
   > 是一种字符节点流
   
   > 只能写字符串/字符，不能写int等，所以要在外面套一层PrintWriter
   
   - `close()`：关闭流。
   
6. **`IOException`** (异常处理)
   - 这是网络和文件操作中**必须捕获**的异常，用于完成任务 5 的错误处理。

### 三、 `java.util.concurrent` 包（多线程并发）

为了让服务器能同时处理多个客户端，必须用到线程池。

**必须掌握的类：**

1. **`ExecutorService`** (线程池接口)
   - `Executors.newCachedThreadPool()`：创建一个可缓存的线程池。
   - `execute(Runnable task)`：提交一个任务（你的 `ClientHandler`）给线程池执行。
2. **`ConcurrentHashMap`** (线程安全的 Map)
   - `put(K key, V value)`：存储用户名和密码。
   - `containsKey(K key)`：判断用户名是否已注册。
   - `get(K key)`：获取密码进行比对。
   - *为什么不用普通的 HashMap？因为多个客户端线程可能同时注册，普通 HashMap 会引发线程安全问题导致数据错乱。*

------

### 四、 `java.lang` 包（基础类，自动导入）

1. **`Thread`** (客户端使用)
   - `new Thread(Runnable target).start()`：在客户端开启一个后台线程专门接收服务器消息，防止主线程被阻塞，导致无法输入。
2. **`Runnable`** (接口)
   - `run()`：实现这个接口，把处理客户端通信的逻辑写在 `run()` 方法里。

   - `format(new Date())`：将当前时间转换为字符串。
2. **`Date`**
   - `new Date()`：获取当前系统时间。
